```text
Eerste practicum Hydrologische processen

Beste studenten

Vrijdag gaat het eerste practicum van hydrologische processen door. In dit practicum gaan jullie werken met twee types software: QGIS en python. Om een vlotte start van het practicum te garanderen, willen we jullie vragen om 1) QGIS te downloaden en 2) om Visual Studio Code met bijhorend python environment te installeren. Om jullie op weg te helpen met VScode, hebben we een installatiegids voorzien welke je kan vinden bij de data voor het eerste practicum. We verwachten dat iedereen QGIS, VScode en bijhorend python environment heeft geïnstalleerd voor aanvang van het practicum. Mensen die dit bij aanvang van het practicum nog niet gedaan hebben, zullen hierbij niet geholpen worden tijdens het practicum.

Indien jullie liever werken met een andere GUI om python code te runnen (pycharm, spyder...), dan kan dit, maar bemerk dat wij enkel ervaring hebben met VScode en jullie dus minder goed hiermee gaan kunnen helpen.

Moesten jullie vastzitten met de installatie van de software, dan zijn wij 30 minuten voor de aanvang van het practicum beschikbaar om jullie verder op weg te helpen. 
```
